# Приложение D: IR-плейбуки (обновлённые после упражнения)

## IR-001: Фишинг с макросами

### Триггер
- Alert: CORR-001 (Макрос + PowerShell)
- Письмо с вложением .docm/.xlsm от нового домена

### Шаги
1. Изолировать рабочую станцию получателя
2. Проверить запущенные процессы: `winword.exe` → `powershell.exe`
3. Собрать forensic-образ памяти
4. Проверить почтовый ящик: пересылки, правила
5. Просканировать всех получателей этого письма
6. Заблокировать домен отправителя на почтовом шлюзе

    Удалить подписки: Remove-WmiObject

    Сменить пароли учёток, использовавшихся на хосте

IR-003: Kerberoasting
Триггер

    Alert: CORR-003 (>5 запросов TGS за 10 мин)
    Event ID 4769 аномальное количество

Шаги

    Идентифицировать учётку, запрашивающую TGS
    Проверить, является ли запрос легитимным (сервисное окно?)
    Если нет — сменить пароль сервисной учётки
    Проверить билеты на всех контроллерах домена
    Проверить SPN: удалить неиспользуемые

IR-004: DNS-туннелирование
Триггер

    Alert: CORR-006 (DNS-аномалии)
    Поддомены >50 символов, редкие TLD

Шаги

    Проанализировать DNS-запросы с хоста
    Декодировать base64 в поддоменах
    Определить объём exfiltrated данных
    Заблокировать домен на DNS-фильтре
    Проверить все хосты на аналогичные запросы
