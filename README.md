## 1. Резюме (Executive Summary)

Проведено Purple Team Exercise для компании в секторе ритейл / e-commerce (~500+ хостов, 30+ регионов). Цель — проверить зрелость SOC и защиту от цепочки атак через корпоративную почту.

**Ключевые результаты:**
- Атака прожила **12 часов** (ожидалось 2–4 недели в организациях без зрелого SOC)
- SOC научился детектировать на **2 фазы раньше**, чем до упражнения
- Разработано и внедрено **8 корреляций** и **12 Sigma-правил**
- Обновлены **IR-плейбуки** по всем фазам kill chain

## 3. Ход упражнения

### 3.1. Red Team: Результаты атаки

| Фаза | MITRE | Результат | Время |
|------|-------|-----------|-------|
| Reconnaissance | — | Собраны контакты, проанализирована почтовая инфраструктура | День 1 |
| Initial Access | T1566.001 | Спуфинг поставщика, макросный документ открыт сотрудником закупок | День 2, 09:15 |
| Execution | T1059.001 | PowerShell payload выполнен, stage-1 загружен | День 2, 09:17 |
| Persistence | T1546.003 | WMI Event Subscription создана (региональный менеджер, непредсказуемое время онлайн) | День 2, 09:45 |
| Privilege Escalation | T1558.003 | Kerberoasting: получены TGS-билеты, оффлайн-крэкинг | День 2, 11:30 |
| Lateral Movement | T1021.001 | Достигнут 1С-сервер через RDP | День 2, 14:00 |
| Collection | — | Собраны базы 1С, конфиги CRM | День 2, 15:30 |
| Exfiltration | — | DNS-туннелирование, частичная выгрузка данных | День 2, 16:00 |
| **Детект SOC** | — | **Alert: PowerShell encoded command** | **День 2, 21:15** |
| **Полный scope** | — | **Все хосты и учётки выявлены** | **День 3, 09:00** |

**Итог:** Атака прожила **12 часов** с момента initial access до первого детекта.

### 3.2. Blue Team: Что детектилось, что — нет

| Фаза | Детект | Результат | Примечание |
|------|--------|-----------|------------|
| Initial Access (фишинг) | Почтовый шлюз | ❌ Не детектил | Спуфинг прошёл, макрос не заблокирован |
| Execution (PowerShell) | EDR + SIEM | ✅ Детектил | Сработало правило на encoded commands |
| Persistence (WMI) | SIEM | ❌ Не детектил | Не было правил на WMI Event Subscription |
| Privilege Escalation (Kerberoasting) | SIEM | ⚠️ Частично | Event ID 4769 логировался, но не коррелировался |
| Lateral Movement (RDP) | SIEM | ⚠️ Частично | RDP логировался, но не анализировалось на аномалии |
| C2 (DNS) | DNS-логи | ❌ Не детектил | Не мониторились длинные поддомены |
| Exfiltration | DLP + сеть | ❌ Не детектил | DNS-туннелирование прошло незамеченным |

### 4.2. Корреляции (MaxPatrol SIEM)

| ID | Корреляция | Условие | Уровень |
|----|-----------|---------|---------|
| CORR-001 | Макрос + PowerShell | Письмо с макросом → winword.exe → powershell.exe за 5 мин | High |
| CORR-002 | Suspicious Scheduled Task | 4698 + powershell + -ExecutionPolicy Bypass | Critical |
| CORR-003 | Kerberoasting | >5 запросов 4769 за 10 мин от одной учётки | High |
| CORR-004 | WMI Persistence | Создание __EventFilter + __EventConsumer | High |
| CORR-005 | RDP Lateral Movement | RDP с рабочей станции не-IT отдела на сервер | Medium |
| CORR-006 | DNS Tunneling | Поддомен >50 символов + редкий TLD | Medium |
| CORR-007 | HTTP Beaconing | Периодические POST с интервалом ±5% | Medium |
| CORR-008 | LOLBAS Execution | certutil/mshta/regsvr32 с подозрительными аргументами | High |

## 8. Выводы

Упражнение продемонстрировало, что даже средняя по сложности атака (фишинг + PowerShell + Kerberoasting) может быть эффективно детектирована зрелым SOC при правильной настройке корреляций и мониторинга.

**Ключевой результат:** SOC научился детектировать на 2 фазы раньше, чем до упражнения. Внедрены детекты на все фазы kill chain, обновлены IR-плейбуки.
